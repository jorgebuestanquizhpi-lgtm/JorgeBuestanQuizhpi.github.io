# Portafolio de Jorge Buestán — GitHub Pages

Sitio estático preparado para publicarse gratuitamente en GitHub Pages.

## 1. Entrar a GitHub con Gmail

1. Abre https://github.com/signup
2. Selecciona **Continue with Google**.
3. Elige tu cuenta Gmail.
4. Escoge un nombre de usuario. Ejemplo: jorgebuestan.
5. Verifica el correo si GitHub lo solicita.

Tu dirección gratuita será:

    https://TU-USUARIO.github.io

## 2. Crear el repositorio

1. En GitHub, pulsa **New repository**.
2. Escribe exactamente: TU-USUARIO.github.io
3. Selecciona **Public**.
4. No añadas archivos iniciales.
5. Pulsa **Create repository**.

## 3. Subir el portafolio

1. Descomprime este archivo ZIP.
2. En el repositorio, pulsa **uploading an existing file** o **Add file → Upload files**.
3. Arrastra todos los archivos y carpetas del portafolio.
4. Pulsa **Commit changes**.
5. Ve a **Settings → Pages**.
6. En **Build and deployment**, selecciona **Deploy from a branch**.
7. Selecciona la rama **main** y la carpeta **/(root)**.
8. Pulsa **Save**.

La publicación puede tardar varios minutos.

## 4. Cambiar fotografías

Las imágenes están en:

    assets/images/

Para cambiar una imagen:

1. Prepara una fotografía horizontal en JPG, PNG o WebP.
2. Convierte o renombra la copia con el mismo nombre del archivo que reemplazarás.
3. En GitHub, abre assets/images.
4. Sube el nuevo archivo con el mismo nombre.
5. Confirma con **Commit changes**.

Archivos disponibles:

- hero-cotopaxi.webp: portada.
- fotografia-montana.webp: proyecto 1.
- thera-adventures.webp: proyecto 2.
- marketing-turistico.webp: proyecto 3.
- thera-explorers.webp: proyecto 4.
- fotografia-documental.webp: proyecto 5 y sección “Sobre mí”.
- diseno-editorial.webp: proyecto 6.

No es necesario modificar el diseño si conservas los mismos nombres.

## 5. Cambiar textos y contacto

Abre content.js en GitHub y pulsa el lápiz de edición.

Desde allí puedes modificar:

- Títulos y descripciones de proyectos.
- Servicios.
- Certificaciones.
- Herramientas.
- WhatsApp, correo, LinkedIn y Behance.

## Importante sobre Gmail

Gmail sirve para entrar y administrar tu cuenta de GitHub. Los visitantes del
portafolio no necesitan iniciar sesión. GitHub Pages no incluye un panel privado
con acceso mediante Google dentro de la propia página.
